# Operation: Secure Drive

A 3D first-person shooter game built in Unity where the player fights through a military base to recover a stolen hard drive.

## About the Game
Operation: Secure Drive is a 3D FPS mobile game. The player enters a military base and fights enemy soldiers to recover a stolen hard drive. Shoot enemies, clear the way, and finish the mission.

## Gameplay
- Enter the **military base**
- **Shoot enemy soldiers** to clear the path
- Recover the **stolen hard drive**
- Complete the **mission** to win

## Features
- First-person shooting
- Enemy soldiers with AI
- Shooting and hit detection
- Mobile-ready controls

## Built With
- **Engine:** Unity
- **Language:** C#
- **Platform:** Mobile (Android)
